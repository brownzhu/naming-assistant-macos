This repository is a customized source snapshot with a new public history. It retains the upstream core, legacy SwiftUI/CLI/Finder Sync targets and test fixtures, and adds the Naming Assistant AppKit target, naming policy, safety coordinator, local suggestions, regression tests and packaging.

Only the `NamingAssistant` product is the current application. Legacy targets and installation scripts retain their original purpose and are not shipped in its `.app` bundle. Historical product documentation is archived under [docs/upstream](docs/upstream/README.md). Obsolete store copy and the previous product's privacy/site pages are not current policies.

Development-machine paths, private working notes, chat identifiers, usage/automation records and prior local Git history are not included in this public repository. This export preserves license notices and describes the upstream relationship explicitly.

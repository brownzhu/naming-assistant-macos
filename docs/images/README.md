# README illustrations

`naming-format.svg` explains the filename convention; `workflow.svg` explains the batch preview/confirmation flow; `finder-folder-workflow.svg` explains the opt-in Finder new-folder suggestion, five-category choice and explicit adoption/History flow. These are original static illustrations with fictional names, not screenshots. The Finder illustration shows `research` as the user's default for the neutral input `test`; it does not imply semantic evidence for that category.

SVGs contain no scripts, external resources, embedded fonts or private paths. Fixed backgrounds preserve contrast across GitHub themes. PNG equivalents are provided for clients without SVG support. Text descriptions and limits are also available in the main README. The Finder illustration was rendered locally and visually checked for clipped text or overlapping elements.
